# Clinical Dataset — Cleveland Heart Disease

Source: UCI Cleveland Heart Disease dataset (via GitHub mirror:
sharmaroshan/Heart-UCI-Dataset)

303 patients, 14 columns, no missing values.

Columns:
age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak,
slope, ca, thal, target

target: 1 = heart disease present, 0 = absent
Class balance: 165 positive / 138 negative
